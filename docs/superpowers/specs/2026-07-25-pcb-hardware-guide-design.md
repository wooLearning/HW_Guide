# PCB HW Design & Validation Guide — Design Specification

## 1. 목표

회로이론의 기초에서 출발해 전자기장, 전송선로, PCB 구조, SI/PI, EMC, 계측, 보드 검증까지 이어지는 한국어 HTML 가이드북을 만든다. 특정 회사의 OJT 요령보다 장기적으로 재사용할 수 있는 원리 이해를 우선하며, 각 개념이 실제 PCB 현상과 측정 결과로 어떻게 이어지는지를 설명한다.

완성본은 다음 질문에 답할 수 있어야 한다.

- 전압·전류·전력·임피던스가 물리적으로 무엇이며 어떤 단위를 갖는가?
- 회로 모델은 언제 유효하고, 언제 장(field)과 전송선로 모델로 넘어가야 하는가?
- PCB의 동박 패턴, 기준면, 유전체, 비아가 신호와 전력의 귀환 경로를 어떻게 만든는가?
- SI, PI, EMC가 왜 분리된 문제가 아니라 같은 전자기 현상의 다른 관점인가?
- 오실로스코프 화면의 파형이 DUT 자체인지, 프로브·대역폭·샘플링이 만든 결과인지 어떻게 판단하는가?
- 보드 전원을 처음 켤 때 무엇을 어떤 순서로 확인하고, 이상 파형에서 원인을 어떻게 좁히는가?

## 2. 독자와 설명 깊이

- 대상: 전기·전자 기초를 다시 다지고 싶은 초중급 학습자와 PCB HW 직무 입문자
- 전제: 고등학교 수준의 대수와 삼각함수. 미적분과 복소수는 필요한 지점에서 다시 설명한다.
- 깊이: 정의 암기보다 물리적 의미, 차원, 경계조건, 근사 가정, 측정 한계를 우선한다.
- 문체: 짧은 문단, 핵심 식, 수치 예제, PCB 적용, 오개념 교정이 반복되는 교재형 문체
- 범위 밖: 특정 CAD 툴 조작법, 특정 회사 프로세스, RF 안테나 설계의 전문 수학, 인증시험 절차의 법률적 해석

## 3. 검토한 구현 방식

### A. 단일 독립 HTML

- 장점: 파일 하나만 열면 되고 배포가 가장 쉽다.
- 단점: 스타일·동작·본문이 한 파일에 섞여 유지보수가 어렵다.

### B. 다중 페이지 정적 사이트

- 장점: 장별 파일이 작고 인쇄·공유가 쉽다.
- 단점: 전체 검색, 진도, 공통 탐색 UI가 복잡해지고 장 이동마다 문맥이 끊긴다.

### C. 단일 본문 + 분리된 자산 — 선택

- `index.html`에 의미론적 장 구조와 학습 내용을 둔다.
- `assets/styles.css`, `assets/app.js`, `assets/calculators.js`, `assets/visualizations.js`에 표현과 동작을 분리한다.
- 빌드 도구와 네트워크 없이 `index.html`을 직접 열어도 동작한다.
- 한 페이지 안에서 전체 검색, 장 이동, 진도 표시, 테마, 인터랙티브 실험을 제공한다.

## 4. 정보 구조

### Part 0. 학습 지도

0. 지도를 먼저 보자 — 집중소자 회로에서 실제 PCB까지, 모델을 바꾸는 기준

### Part I. 회로를 읽는 언어

1. 단위·전하·전압·전류·전력 — 에너지와 보존법칙
2. DC 회로 — Ohm, KCL/KVL, 등가회로, 분압·분류
3. C와 L — 에너지 저장, 연속조건, RC/RL 과도응답
4. AC와 주파수 — 복소수, 페이저, 임피던스, 공진, Bode 관점
5. 실제 부품 — 기생 RLC, 다이오드·MOSFET·레귤레이터의 핵심

### Part II. 회로도 밖의 물리

6. 전자기학의 최소 골격 — E/H/B, flux, Maxwell 방정식의 의미
7. 전송선로 — 파동, 특성임피던스, 지연, 반사, 종단

### Part III. PCB라는 물리 구조

8. PCB 재료·제조·스택업 — 동박, FR-4, Dk/Df, 비아, 패드, 솔더마스크
9. 배치·배선·귀환 경로 — 루프 면적, 기준면, 층 변경, 접지의 의미
10. Signal Integrity — edge rate, 불연속, 크로스토크, 타이밍, eye
11. Power Integrity — PDN, 디커플링, plane resonance, target impedance
12. EMC/EMI — source-path-victim, 공통/차동 모드, 방사·전도, 차폐·필터

### Part IV. 보이는 것과 실제 신호

13. 오실로스코프 — 대역폭, rise time, 샘플링, 메모리, 트리거
14. 프로브와 측정 — loading, ground lead, differential/current probe, 안전

### Part V. 검증과 문제 해결

15. Bring-up·검증·고장분석 — 전원 인가 전 검사, current-limited power-up, rail/clock/reset/interface, 가설-측정-판정 루프

### 부록

- 공식·단위 치트시트
- 용어집
- 설계·측정 체크리스트
- 참고문헌과 출처 등급
- 6주/12주 학습 경로

## 5. 장 내부 템플릿

각 장은 가능한 범위에서 같은 순서로 읽힌다.

1. `왜 배우나`: 바로 뒤의 PCB 현상과 연결
2. `한 문장 직관`: 식보다 먼저 잡을 물리적 그림
3. `핵심 원리`: 정의, 보존법칙, 경계조건, 근사 가정
4. `식과 단위`: 기호 정의와 차원 확인
5. `수치 예제`: 손으로 따라갈 수 있는 한 단계 계산
6. `PCB에서`: 배치·배선·부품·스택업에 나타나는 모습
7. `측정에서`: 오실로스코프나 DMM에서 확인하는 방법과 한계
8. `오개념 경보`: 흔한 잘못된 설명을 짧게 교정
9. `인터랙티브 실험`: 입력을 바꾸고 결과를 관찰
10. `셀프 체크`: 답을 펼쳐볼 수 있는 2~4개 질문

## 6. 핵심 시각화

1. 전압분배기와 부하 효과
2. KCL 노드의 전류 보존
3. RC 충·방전과 1τ/5τ
4. RLC 공진과 감쇠
5. 페이저 회전과 시간파형
6. 기생성분 때문에 달라지는 실제 커패시터 임피던스
7. 전하·전류가 만드는 E/H field와 에너지 흐름
8. 전송선로의 입사파·반사파와 반사계수
9. PCB 스택업 단면과 field confinement
10. 연속 기준면과 split plane 위의 귀환 경로 비교
11. 인접 배선의 capacitive/inductive crosstalk
12. PDN target impedance와 decoupling 조합
13. 공통 모드와 차동 모드 전류
14. 프로브 ground lead 길이에 따른 링잉
15. 샘플링·앨리어싱
16. 대역폭과 관측 rise time
17. 보드 bring-up 의사결정 흐름

시각화는 장식이 아니라 입력, 물리 모델, 관측값의 관계를 보여주는 도구다. 모든 캔버스에는 텍스트 요약 또는 표를 함께 제공한다.

## 7. 화면 설계

- 기본 인상: 밝은 공학 노트. 짙은 남색 본문, 동박색 강조, 청록색 측정 신호, 적색 경고
- 데스크톱: 고정 목차 + 중앙 본문 + 현재 장의 핵심 기호/진도를 보여주는 얇은 오른쪽 레일
- 모바일: 상단 진행 막대와 접이식 목차. 본문은 한 열
- 긴 글의 피로를 줄이되 모든 내용을 카드로 쪼개지 않는다. 카드형 표면은 예제, 실험, 오개념, 측정 팁에만 쓴다.
- 한글 본문은 시스템 산세리프, 식·단위·파형 값은 고정폭 글꼴을 사용한다.
- 다크 모드, 글자 크기 조절, 전체 검색, 읽은 장 표시, 인쇄 모드를 제공한다.

## 8. 동작과 상태

- 장 링크는 같은 문서의 `section[id]`로 이동하며 현재 장을 목차에서 강조한다.
- 검색은 제목·본문·키워드를 대상으로 하고 결과에서 해당 위치로 이동한다.
- 읽은 장, 테마, 글자 크기는 `localStorage`에 저장한다. 저장이 차단되어도 기능은 메모리 상태로 계속 동작한다.
- 모든 계산 입력에는 현실적인 최소·최대 범위와 단위가 표시된다.
- 잘못된 수치에는 계산하지 않고 입력 근처에 이유를 표시한다.
- `prefers-reduced-motion`에서는 파형 애니메이션을 정지하고 정적 상태를 보여준다.

## 9. 기술 선택

- HTML5, CSS3, 바닐라 JavaScript
- 인터랙티브 도식: 인라인 SVG 우선, 연속 파형은 Canvas
- 외부 폰트·CDN·프레임워크 없음
- 계산 핵심은 DOM과 분리된 순수 함수로 작성해 Node 내장 테스트 러너로 검증
- 모든 파일은 UTF-8

## 10. 자료 검증 원칙

출처 우선순위는 다음과 같다.

1. 표준 원문·기관 페이지: IPC, IEC, IEEE, FCC
2. 계측기·반도체 제조사의 공식 primer/application note: Tektronix, Keysight, Rohde & Schwarz, TI, Analog Devices
3. 대학 공개강의·정평 있는 교재
4. 보조 설명 자료

표준 번호와 판본은 공식 revision table에서 확인한다. 경험칙은 법칙처럼 쓰지 않고 적용 조건을 함께 쓴다. 예를 들어 “trace는 edge가 충분히 느리면 전송선로가 아니다”처럼 시간지연과 rise time의 비로 조건을 명시한다.

## 11. 품질 기준

- 콘텐츠: 모든 장에 직관, 식/단위, PCB 연결, 측정 연결, 오개념, 셀프 체크가 있다.
- 계산: 대표값, 0 경계, 큰/작은 값에서 단위와 결과가 맞다.
- 접근성: 키보드만으로 탐색·검색·실험 조작이 가능하고 포커스가 보인다.
- 반응형: 390 px, 768 px, 1440 px 폭에서 가로 스크롤 없이 읽힌다.
- 인쇄: 목차 UI와 조작부를 숨기고 모든 장이 정상 흐름으로 출력된다.
- 성능: 네트워크 요청 없이 첫 화면이 열리고 콘솔 오류가 없다.

## 12. 범위 관리

첫 완성본은 16개 장을 모두 제공하되, RF 안테나·고급 S-parameter·규격별 인증시험은 개념 소개와 다음 학습 경로까지만 다룬다. 향후 각 장을 별도 심화권으로 늘릴 수 있도록 용어, 시각화, 계산기를 독립 컴포넌트로 만든다.
